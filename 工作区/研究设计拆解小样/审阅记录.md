# 临床设计小样的两席AI审阅

两席与提取者分开、只读，没有参与主卡施工；事实席independent_candidate_review，方法席design_method_review。审阅日期2026年10月4日，覆盖抽取规范design-extract-v0.1及三实例revision 1。原件版本以[来源回执](来源回执.json)的哈希为准。

结论：关键事实经核对并已按发现修订；方法学只支持注明条件的设计借鉴。三篇继续保持候选状态，没有发布为通用设计规范。两席均为AI，意见一致不保证科学正确；重大争议或实际临床研究方案须专业复核。

## 事实核验

事实席独立读三篇原文及Moreira补充Table S1，确认样本量依据、分析人群、揭盲删失/不插补、Magen时间零点/匹配/换组/风险窗/单位、Bar-On内部对照和人群重叠谨慎表述。

发现F1：Magen结果错标为Table 3，实为Table 2、官方PDF第8页；已修正。事实席自主加核、非提取者指定的细节：Bar-On重症确诊后14天内发生但用阳性检测日计事件，已补差异卡。附件覆盖有限，不将“未读到”写成“未做”。

## 方法学审阅

下表为【审阅者判断或建议】，不是作者报告事实，也不是质量分数。

| 编号 | 发现或使用限度 | 本轮处理 |
|---|---|---|
| M1 | RCT需明写有症状且确诊，而非笼统感染；补充PDF第7–8页 | 已补主卡终点及定位 |
| M2 | Bar-On重症按确诊日归组，率比方向为对照÷四针；官方正文第3页 | 已补时间结构与率比方向，防止误套1−率比 |
| M3 | Magen风险窗是起窗仍未删失者的条件比较；对照接种引起删失若与结局风险相关，可能产生偏倚。延迟删失检查不证明假设成立；正文第3、5页 | 原文规则已保留；模式迁移条件保留该限制 |
| M4 | Bar-On内部早期对照依赖早期无明显效应、短暂选择偏倚已减弱等假设；同人不同时段仍受行为、检测及日历风险影响；正文第7–8页 | 候选模式明确不能据此保证已消除混杂 |
| M5 | RCT短随访及稀少重症事件，不能证明罕见风险不存在或稳定估计重症/死亡增益；Delta时期效果不能直接外推Omicron；Results、Discussion | 主卡明确结论限度，不扩大效应解释 |

方法席另发现并确认已修：Magen前3天医疗接触排除、Poisson敏感性只覆盖PCR感染、Table 2定位；Moreira可评价人群、IRR及第7天感染证据窗口。

可借鉴：共同治疗背景上的随机追加比较、共同资格与同日起跑、明确动态人日与替代对照。条件性借鉴：匹配变量、风险窗、病例定义、对照交叉和删失分析。不可直接复用：现成样本量、短暂早期对照的无偏保证、跨变异株/人群结论、可能重叠资料的独立复现计数。

## 审阅范围和关闭状态

两席未全面核Moreira完整方案，也未全面核另两篇全部附件或个体数据。此处的“已修”表示提取者已依据原文落实到卡片；两席随后确认的范围在来源与复核中补记，不冒称全量重新审阅。未关闭的事项是上述迁移限制和专业判断需求，不是待补写的原论文事实。

方法席有限复读确认M1、M2关闭，M3–M5限度保留忠实、未反写作者事实，候选状态明确；没有扩大到新取得的Magen附件全面审阅。

事实席窄复核确认F1关闭；新增的症状性终点、第7天感染条件、IRR、Bar-On事件日期及率比方向均吻合原文，指定字段未发现剩余错误。此结论不代表全面附件或偏倚审计。
