# 临床论文设计拆解小样

这份小样检验“设计类型、可复用模式、论文实例”能否分开保存。完成两张主卡和第三篇差异比较，结论是：骨架可试用，合并时必须保留时间、对照和偏倚控制的分支，暂不能成为所有临床研究的统一规范。

轨道位置：L2小样验证。R级：沿用本项目R2。判级理由：只整理公开论文并作候选文档，不处理患者个体数据或作临床决策。签发：PI于2026年10月4日经协调会话转达本轮具名范围，含两席AI审阅及未来Obsidian管理方向。

## 两分钟先看这里

| 样例 | 最值得保留的设计信息 | 不能照搬的地方 |
|---|---|---|
| [随机试验主卡](随机试验卡.md) | 随机分配、实际注射、可评价人群分开；安全和疗效分别有窗口 | 10,000人的样本量来自安全规模目标；提前揭盲和短随访不能当通用安排 |
| [匹配队列主卡](观察队列卡.md) | 当天资格、当天匹配、共同起跑；对照交叉后成对删失 | 匹配不消除未测混杂；排除和匹配损失限制人群代表性 |
| [第三篇差异](模式差异.md) | 用动态人日与暴露后3–7天内部对照，是另一分支 | 内部早期对照不能保证无偏；两篇人群可能重叠，不能算独立复现 |

两席分别核事实和审方法，已纠正表号与结局/验证范围，详情见[审阅记录](审阅记录.md)。AI审阅辅助发现问题，不保证科学正确；重大争议须专业复核。顶刊发表不等于适合作推荐模板。

[候选模板v0.1](候选模板v0.1.md)包含分层保存、增量修订和未来Obsidian约定。[候选模式](可复用模式.md)独立于原文事实；[来源与复核](来源与复核.md)列明实际读到的正文、附件及限度。三篇均为2022年NEJM原创研究，处于近五年范围。

## 这次改了哪些字段

增加安全/疗效并列、分析人群、时间零点/起窗/终止的分离、动态身份、效应量参照方向与单位、附件核对状态、研究关联和人群重叠状态。新增字段可按需补提，模式标签修订只更新下游；源文更新或误抽则针对性重读，不保证任何修订都零重跑。

尚未解决：跨论文实际重叠人数、其他设计类型覆盖、正式Obsidian库的现有布局及PDF归属。当前仅公开材料的小样；不扩样、不建软件或正式技能、不写Zotero、不装插件，不创建或迁移Obsidian库。

先前客户端“确认导入后自动AI复核并衔接全文”的任务保持未完成，未在本轮施工；本轮小样不冒充该任务验收。
